# WordPress Child Theme

A simple child theme for the Twenty Twenty-Four theme, created as part of my WordPress course.

## Installation

1. Download this repository as a ZIP file.
2. In WordPress, go to **Appearance → Themes → Add New → Upload Theme**.
3. Upload the ZIP and click **Install Now**.
4. Click **Activate**.

## Requirements

- WordPress 6.0 or later
- Parent theme: Twenty Twenty-Four

## Files

- `style.css` - theme header and custom styles
- `functions.php` - loads parent and child stylesheets
